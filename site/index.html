Made for a screen in the hallway

Big touch targets, instant feedback, and nothing to log in to. Everything below is in the demo above.

Your token stays on the server
The container holds the Home Assistant token and only lets the screen see and control the entities you list. Nobody can lift it off the screen in your hallway.
One YAML file
Rooms, scenes, apps and entity IDs live in kiosk.yaml, with autocomplete in your editor. Save it and the screen reloads by itself.
Fast on a Raspberry Pi
Taps update right away. Every theme has a lite mode without blur, so even a Pi 3 keeps up.
It reacts to your home
A doorbell ring opens the camera over everything, even from standby. Any entity can open any app.
A clock when idle
Standby faces show the time, the weather and the widgets you pick, plus a dim red night face for the hallway at 3 a.m.
Yours to change
Three themes, drag-and-drop editing on the screen, and runtime packs for your own widgets, faces and themes. No rebuild needed.

How it works

The screen only ever talks to the container. The container talks to Home Assistant.

  1. Wall screen A Pi, a tablet or any browser. No token, no login.
  2. only entities in kiosk.yaml
  3. Open HomeView One Docker container. It serves the screen, holds the token and filters every call.
  4. token added here
  5. Home Assistant Use a non-admin user, so even a leaked token can't change settings.

Three themes, four standby faces

Switch with one line in kiosk.yaml, or add your own as a pack.

Your whole wall in one file

List your apps, put them on the dashboard, and pick what wakes the screen. The container reads this file and refuses everything it doesn't list.

Read the configuration reference 

theme: glass
weather: weather.forecast_home

apps:
  - id: lights
    type: lights
    groups:
      - name: Living Room
        lights: [light.ceiling, light.floor_lamp]
  - id: front-door
    type: camera
    camera: camera.front_door

dashboard:
  - - clock
    - weather
    - { app: lights, group: living-room }
    - { type: lock, entity: lock.front_door }

events:
  - entity: event.front_door_doorbell
    open: front-door   # ring opens the camera

The hardware

The project was built on this exact screen: the official 7-inch display in a white case, on a hallway wall.

  • Raspberry Pi 5 2 GB is plenty for one browser. A Pi 4 works too, with graphics: lite. raspberrypi.com
  • Touch Display 2 (7") with white case Waveshare's case around the official 720×1280 DSI touch screen. About €124. Amazon.nl
  • Belkin 30 W USB-C charger Enough for a screen and a browser. The Pi only wants 5 A for power-hungry USB devices. About €15. Amazon.nl

Then follow the Raspberry Pi kiosk guide: Pi OS Lite, cage and Chromium, booting straight into the dashboard.

Running in two minutes

On any machine that can reach Home Assistant.

compose.yaml 
services:
  open-homeview:
    image: ghcr.io/miladd3/open-homeview:latest
    restart: unless-stopped
    ports:
      - 8080:8080
    environment:
      HA_URL: http://homeassistant.local:8123
      HA_TOKEN: your-long-lived-access-token
    volumes:
      - ./config:/config

Run docker compose up -d, open http://<server>:8080, then follow Getting started to make a token and your first kiosk.yaml.
